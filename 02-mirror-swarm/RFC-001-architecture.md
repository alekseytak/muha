# RFC-001 · Проект II «Рой-Зеркало» — эмпатическое сознание с рефлексией

- Статус: DRAFT v1.0 · Домены: atqec / memory / hardware
- Источники вдохновения: О. Батлер (гиперэмпатия), Ф.К. Дик (mood organ),
  О. Хаксли (коллективная медитация), С. Лем (Солярис-зеркало),
  Н. Козырев (временная асимметрия), С. Улам (хаос против Дня Сурка)

## 1. Мотивация

Рой, который не только решает, но и ЧУВСТВУЕТ: награда одного — радость
всех, штраф одного — боль всех. Перед рискованным действием рой смотрит
в зеркало Козырева и видит эхо последствий. Творчество гарантировано
автоматами Улама — рой не застревает в локальных минимумах.

## 4. Контракты

- Гормональный профиль: dict {dopamine, serotonin, oxytocin, adrenaline,
  cortisol, noradrenaline, octopamine, gaba}, baseline 0..100.
- Эмоция: («радость»|«злость»|«страх», intensity 0..1).
- Зеркало: {echo, dissonance, paradox_likelihood}.
- Медитация: {sync_order 0..1, freq_hz, state}.

## 5. Взаимодействие с OS Глаголов

- Гормональный сдвиг НЕ меняет разрешённые глаголы — только risk_appetite
  внутри контекста verb-act (субъект остаётся в рамках роли).
- paradox_likelihood > 0.66 → Guardian обязан «эскалирует» (L4).
- Состояние «страх» → risk_appetite −0.4 → контекст risk_level повышается.

## 6. Метрики приёмки

- Эмоциональное многообразие устойчиво (аудит как в
  AI_Emotional_Audit_Final_Report.pdf: H1-циклы, без коллапса в шум);
- медитация достигает sync_order > 0.8 за ≤ 60 с модельного времени;
- зеркало ловит ≥ 90% инъектированных парадоксов в тестах;
- автомат Улама повышает разнообразие траекторий ≥ +20% без падения success_rate.

## 7. Риски

- Эмоциональная контагиозность → паника роя: ограничение intensity ≤ 0.5
  и затухание в EmpathyBus.
- Хаос Улама ломает обучение: инъекции только в exploration-фазе.
