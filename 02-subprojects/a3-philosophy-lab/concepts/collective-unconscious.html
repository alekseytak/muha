Registry как общая память роя

К. Юнг
Registry (append-only, sha256 chain)

Каждое действие агента оставляет след в append-only Registry. Следы не удаляются — они только дописываются. Каждый след — кандидат в золотые яблоки.

class Registry: def __init__(self): self.traces = [] # append-only self.chain = sha256() def record(self, action, agent_id): trace = { 'action': action, 'agent': agent_id, 'timestamp': now(), 'hash': self.chain.hash(action + str(agent_id)) } self.traces.append(trace) # нельзя удалить return trace
