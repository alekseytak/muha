Каждый эпизод может стать «золотым яблоком» — каноническим прецедентом. Голосование роя должно набрать ≥66% голосов. Принято 200 яблок, verify_chain()=True.

def propose_golden_apple(episode): trace = registry.hash(episode) votes = swarm_vote(trace) # ≥ 66% для canon if votes >= 0.66: registry.canon.append(trace) # → Золотое яблоко return votes
