# План реализации агента МУХА (Omega-Agent)

Версия: 1.0
Дата: 2026-11-08
Статус: черновик

## 1. Видение

Построить автономного агента на базе реального коннектома дрозофилы (1 515 нейронов / 58 674 связи), где каждая философская концепция из PHILOSOPHY.md — исполняемый модуль. Агент проходит путь Student → Teacher → Рой → Омега, принимает решения через verb-act + GateKeeper, хранит память в Registry (append-only, sha256), голосует за «золотые яблоко», обладает эмпатией, гормонами, рефлексией и устойчивой ризомной сетью.

Результат: агент, который можно запустить в 3D-браузере (A1), показать презентацией (A2) и изучить через философскую лабораторию (A3).

## 2. Архитектурная схема

UI / Презентация (A2) — presentation.html (кассетный футуризм)
         │
3D Коннектом 뷰ер (A1) — Three.js + InstancedMesh + OrbitControls
         │
Ядро агента (Python)
  VerbAct + GateKeeper + Registry + Swarm + OmegaRegistry
  LIF SNN + Hormone + Empathy + KozyrevMirror + Rhizome
         │
Реальные данные: var/flywire-role/nodes.csv + edges.csv

- Голосование роя ≥66%

- Философская лаборатория открывается (27 страниц)
