## Что проверить первым делом после перезапуска

1. `memory_profile` — читается ли профиль памяти.
2. `memory_remember` с коротким фактом — проходит ли запись.
3. Если снова `disabled` — откатить файл из копии:

   ```sh
   cd ~/.dsh/profiles/web/node_modules/dsh-native-memory/lib
   cp index.mjs.bak-before-inject index.mjs
   ```

   и записать в `AUDIT.md` §32.3, что патч `inject` не помог: значит
   `storageDomain` в этом профиле не поднимается по другой причине.
4. Если `memory_*` инструменты **исчезли** — это ожидаемое следствие
   объявленного `inject`: плагин ждёт зависимость и не запускается.
   Откат тот же.
