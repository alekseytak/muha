## Проверки на реальных файлах

Проверено стандартным Python csv без преобразования ID в float:

- Completeness: 138 639 строк, колонки с пустым именем (FlyWire ID) и `Completed`.
- file1: 139 255 строк. Для всех 138 639 ID графа есть ровно одна строка
  в file1. Покрытие 100%, порог 95% пройден.
- Все три конечные координаты soma доступны у 118 093 нейронов графа.
- Для остальных 20 546 доступны все три координаты pos. Суммарное покрытие
  soma с fallback на anchor 100%, пропущенных координат нет.
- file4: 24 406 строк, включая 3 047 строк hemibrain.
  Строки hemibrain нельзя включать в FlyWire-склейку.
- Непустые `nps` после исключения hemibrain покрывают только 21 352 ID графа,
  то есть 15.4011%. Полного покрытия регионов этими файлами нет.
- У parquet проверены сигнатуры PAR1 в начале и конце, вычислена SHA-256.
  Полное декодирование parquet и проверка колонок/рёбер НЕ выполнялись:
  в окружении нет pandas/pyarrow. Это не гейт успешного ingest.

## Исправления исходного плана

Документация авторов подтверждает, что soma и pos заданы в вокселях 4×4×40 nm.
Перевод в µm: x×0.004, y×0.004, z×0.04. При будущей конвертации сохранять
`coord_source` отдельно, смешение soma и anchor не даёт измеренной длины аксона.

В `nps` записаны три наиболее иннервируемых нейропила, **отсортированные
алфавитно**. Первый элемент не является главным регионом. Пример значения:
`AL_LH_MB_CA`. Нельзя без словаря разбивать по подчёркиванию, поскольку
оно встречается внутри имён нейропилов. Хранить исходное значение до появления
проверенного парсера и определения семантики `region`.

file4 не закрывает геометрию регионов всего графа. Для оставшихся 84.6%
потребуется дополнительный источник регионов той же FlyWire 783 либо
явная политика unknown. Не подставлять выдуманные регионы.

`top_nt` в документации является предсказанием нейромедиатора. Сам по себе
он не доказывает возбуждающий/тормозный эффект для любой пары рецепторов.
Задержки 1.8 ms и нормализация весов не применялись. Это будущие модельные
решения, не свойства скачанных измерений.

## Волна 1: декодирование и ingest (после установки pyarrow 26.0.0)

`Connectivity_783.parquet` декодирован. Структура оказалась благополучнее
плана: 15 091 983 строки, 8 колонок.

- `Presynaptic_ID`, `Postsynaptic_ID` — сами FlyWire `root_id` (int64), а не
  позиционные индексы → ключ склейки с file1/file4 лежит прямо в графе,
  обход через `Completeness` не требуется.
- `Connectivity` — число синапсов (1…2405, нулей нет) → это `synapse_count`.
- `Excitatory` — знак ребра ∈ {−1, +1}, авторская per-edge пометка (первичнее
  per-neuron `top_nt`) → это `edge_class`.
- `Excitatory x Connectivity` — подписанный вес; `__index_level_0__` — мусор.

Целостность графа (numpy по всем 15M рёбер): **0 self-loops**, **0 параллельных
пар** (все 15 091 983 уникальны, кратность 1), **0 пар со смешанным знаком**.
Дедупликация и разрешение конфликтов знаков не нужны; `edge_policy` =
{allow_self_loops: false, merge_parallel: true}.

### Найденная ловушка точности (исправлена в ingest)
FlyWire `root_id` ~7.2e17 > 2**53. `models._as_int` парсит id через `float()`,
из-за чего соседние id схлопывались бы в один (ложные «duplicate node_ids»,
разрыв edges↔nodes). Решение волны 1: **reindex в компактные 0..N-1** на выходе;
оригинальные root_id сохранены доп-колонкой `flywire_id` в nodes.csv и sidecar
`flywire_id_map.json`. Тот же точный int применён при чтении `root_id` из
TSV/CSV (не через float). Закреплено тестами `test_local_reindex_*` и
`test_real_reindex_*`.

### Контрактные решения (честные рамки)
- `weight` = пусто (None): connectome не даёт синаптических весов
  (scientific_scope §2); структурная величина — `synapse_count`.
- `delay_ms` = 0.0: задержка — будущая модель; 1.8 ms при dt=1.0 не проходит
  квантование в `validate_nodes_edges`, поэтому ноль, а не выдумка.
- `region` = строка `nps` дословно, без парсинки; для рёбер без file4 — "".
  Ни одного региона не придумано.

### Правила отбора подграфа волны 1
`subgraph_rule = degree-induced-subgraph`: top-N нейронов по суммарному числу
синапсов, индуцированный набор рёбер. Опирается только на граф → воспроизводимо,
не зависит от разрежённых аннотаций. Таргет-региональный выбор (optic→CX→motor,
AL→MB→дофамин) **осознанно отложен**: честный `region` сейчас задать нельзя,
нужен проверенный neuropil-парсер и источник регионов на весь граф.

### Гейт готовности (реальный прогон, target=2000)
`scripts/run_flywire_ingest.py` → `var/flywire/` (gitignore):
**2000 узлов, 154 173 ребра**, манифест валиден по `connectome_manifest.schema.json`,
`load_connectome` собирает `ConnectomeGraph` без ошибок. Покрытие `region` в
полученном подграфе — **9.35%** (хабы в основном без `nps` — ожидаемо, это
зафиксированное ограничение, не провал). Тесты: `test_flywire_ingest` (13,
синтетика, идут без данных) + `test_flywire_real_data` (3, skipif без pyarrow/файлов).
Весь набор агента: 465 зелёных.

### Чего волна 1 НЕ утверждает
Это не «модель мозга» и не биологически валидированный субграф: отбор по степени,
веса/задержки не заданы, нейроны как excitatory/inhibitory не классифицированы
(`node_classes` = одна категория unknown). Претензии уровня `simulation_result`/
`engineering_performance` — и только.

## Волна 2: реальный подграф крутит SNN (weight policy + гейт §6)

Волна 1 доказала «граф собирается». Волна 2 — «граф управляет нейронами»:
впервые реальный FlyWire-подграф прогоняется через `SparseLIF`.

### Найденная ловушка: откат весов на сырые counts
`ConnectomeGraph` при `weight=None` подставляет `synapse_counts` (models.py).
Для реальных данных это все положительные числа 1..2405: знак E/I потерян,
магнитуды абсурдны → наивный запуск в LIF даёт гарантированный runaway.

### Решение: `src/science/snn/weights_policy.py`
- `signed_structural_weights(graph, ...) -> (E,)` — чистая функция.
  Знак — **из данных**: `edge_class` (excitatory/inhibitory, проставлен
  ингестом по колонке Excitatory пресинапа). Магнитуда — **модельное
  допущение**: `min(synapse_count, count_saturation) * w_syn_per_count`;
  по умолчанию 20 × 0.05 = планка 1.0, согласована с `STDPParams`
  (exc [0, 1], inh [-1, 0]) — policy-веса годятся как старт для STDP.
  Неизвестный/отсутствующий `edge_class` → fail-fast, как unknown NT в
  `plasticity_sparse`.
- `graph_with_signed_weights(graph, ...)` — тот же граф с подписанными весами.

### Гейт на реальных данных (test_flywire_real_data, target=300, 5 seeds)
Подграф 300 узлов / 6410 рёбер → policy: 3147 exc / 3263 inh, |w| ≤ 1.0,
mean|w| ≈ 0.43 → `simulate_lif` 1000 шагов, dt=1 ms, `LIFParams(sigma=3.0)`
(шум — фоновая спонтанная активность, инженерная константа; без него сеть
из E_L молчит бы всегда). Утверждаются только инварианты validation_plan §6:
все состояния конечны (ни NaN, ни inf); не всё молчит; ни один нейрон
< 100 Hz (планка от припадочной синхронизации). Инварианты проверяются на
каждом из 5 seeds (7, 13, 21, 42, 99): средняя частота 2.9–3.2 Hz — внутри
инженерной полосы [1, 20] Hz; max ≈ 8–11 Hz; 12–20 молчащих из 300.
Разброс между запусками меньше ширины полосы; пороги теста — грубые
инженерные границы, а не подгонка под измеренное. Полоса —
`engineering target, не биологический факт`.

### Сравнительный базлайн: ловушка масштаба — реальна, знак — null-результат
Парный тест на том же подграфе и тех же seeds (`test_bazlayn_syrie_counts_...`):
- **policy-веса** (scale-cap 1.0): средняя 2.9–3.2 Hz — в полосе [1, 20] Hz;
- **сырые synapse_counts** (наивный фолбэк `ConnectomeGraph` без политики,
  mean 36.5, max 2405): средняя ~240 Hz, max ~325 Hz — сеть на рефрактерном
  потолке (асимптота ~333 Hz при t_refrac=2 ms), 5/5 seeds. Численность
  симулятора держится и там (ни NaN) — ломается модель весов, не солвер.

Разрыв десятикратный — policy ловит именно **scale-cap**. Честный
null-результат: при одинаковых магнитудах сброс знака в «всё положительное»
не меняет safety-статистику в этом режиме (2.9–3.2 Hz в обеих руках):
активность задаётся шумом, рекуррентный вход при |w| ≤ 1 мал. Знак —
контрактное свойство (данные E/I, старт для пластичности), но измеримый
эффект в текущем режиме не показан и не заявляется.

### Чего волна 2 НЕ утверждает
Частоты — свойство выбранной модели (w_syn, saturation, sigma, dt), а не
измерение FAFB; задержки по-прежнему 0; это `simulation_result` /
`engineering_performance`, не биологическое совпадение. Safety-инварианты
теперь не зависят от выбора seed (≥5 seeds по validation_plan), добавлен
базлайн весовых моделей (policy vs сырые counts). Обучающих базлайнов
(STDP против frozen/shuffled на реальном графе) здесь нет и не заявляется;
эффект знака E/I в текущем шум-доминированном режиме — null (см. выше).
