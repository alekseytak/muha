## 1. Память DSH: почему выключена

`memory_remember` отвечает: «the storage-domain facility is not available in
this profile — memory is disabled here».

Что найдено:

| звено | состояние |
|---|---|
| пакет `dsh-native-memory@0.2.0` в профиле `web` | установлен, в `dsh.profile.bundles` |
| инструменты `memory_*` | зарегистрированы (видны агенту) |
| сервис `storageDomain` | плагин его **не получает** |
| строки `storage`, `storage-json`, `storage-domain` | есть в бандле `@deepseek-ai/dsh-web-app` (вставка, не отключение) |

Причина в коде плагина (`lib/index.mjs`):

```js
const inject = ["tools"];                       // storageDomain НЕ объявлен
...
const storageDomain = ctx.get("storageDomain"); // читается в момент apply
if (storageDomain === void 0)
  throw new MemoryError("MEMORY_DISABLED", ...);
```

Плагин не объявляет `storageDomain` среди внедряемых зависимостей и читает
сервис синхронно при загрузке. Если сервис в этот момент ещё не поднят (или
живёт в другом слое композиции), память остаётся выключенной навсегда, хотя
инструменты зарегистрированы.

Кандидаты решения (каждый требует перезапуска `dsh web`):

1. Обновить `dsh-native-memory`, если в новой версии `inject` содержит
   `storageDomain` — проверить не удалось: npm-реестр недоступен из этой сети.
2. Локально поправить `inject` в установленном пакете — правка в
   `node_modules`, теряется при переустановке.
3. Поднять `storage-domain` раньше в пользовательском слое
   `~/.dsh/profiles/web/cordis.patch.yml`.

Пока память выключена, вехи проектов пишутся в репозиторий: этот файл,
`AUDIT.md`, `ARCHITECTURE.md`.

## 2. SenseNova: что удалось прочитать

Карточку модели скачать не удалось (SSL/403 на этом канале), поэтому
**рецепт обучения через учителя не подтверждён** — выдумывать его нельзя.
Что прочитано достоверно из `config.json`:

```json
"hidden_size": 4096,
"loop_settings": {"counts": [2], "start": 4, "end": 28, "eval_count": 2},
"mhc": {"start": 4, "end": 28, "streams": 2, "iterations": 20,
        "fixed_identity": false, "pre_scale": 1.0}
```

То есть лупы включаются не на всех слоях, а с 4-го по 28-й, два прохода,
и параллельно идут два потока `mhc` с 20 итерациями. Архитектура —
`SenseNovaLoopForConditionalGeneration`, `model_type: sensenova_loop`,
apache-2.0, мультимодальная (`image-text-to-text`), `custom_code` (нужен
`trust_remote_code`).

Для MUHA из этого переносимо ровно одно: **луп как повторный проход по
средним слоям**, а не как внешний цикл «повторяй, пока не получится». Это
согласуется с ZaLoop: там луп — то, что надо тормозить, а не то, чем надо
усиливать модель.

## 3. ZaLoop: найден, прочитан

`~/DSH-Research-Lab/library/ergo/zaloop.md` (188 строк) — спецификация
контроллера лупов. Основание: `~/документы /🔄Os глаголы и лупы .md`,
разделы 1.2, 2.1, 4, 5; тормоза взяты из
`~/muha/03-terminal-agent/core/autonomous.py:250-285`.

Пять ступеней, только вверх внутри лупа, сброс при смене рамки:

| ступень | условие | что разрешено |
|---|---|---|
| 0 `normal` | ни один порог не превышен | всё |
| 1 `nudge` | один повтор подряд | всё + подсказка «результат уже получен» |
| 2 `reduce` | 2 повтора подряд или `repeatRatio > 0.35` | `maxSteps` вдвое, окно истории до 3 |
| 3 `shadow` | 3 повтора, или цикл периода 1–4, или `deniedRate > 0.5` | только предложения, бюджет не тратится |
| 4 `stop` | цикл после `shadow`, или 2 ошибки подряд, или бюджет кончился | остановка, задача в `PENDING`, `HumanReviewTicket` |

Сигналом считается **отпечаток действия** `verb|domain|object`, а не текст
команды: `cat notes/a.txt` и `sed -n 1p notes/a.txt` — одно действие.

Два честных ограничения из документа, которые надо сохранить при переносе:

* пороги не имеют значений по умолчанию — контроллер обязан получить файл
  порогов с `sha256` и отказывается работать без него;
* верхняя граница (рассеяние) **объявлена, но неактивна**: доля новизны во
  всех 47 пересчитанных ячейках равна 1.00, значит граница ничего не
  различает и как гейт непригодна.

Критерий готовности включает мутанта: контроллер без детектора цикла обязан
провалить проверку `A B A B`.

## 5. Что из этого следует для MUHA

### 5.1 Зрение не должно быть подписью к картинке

Сейчас `core/vision.py` зовёт `deepseek-v4-flash-vision-exp` и получает
текст. Это работает, но это **не зрение мухи**: большая модель пересказывает
картинку словами. Мухе нужен не пересказ, а вектор восприятия.

Три пути, по возрастанию честности:

| путь | что даёт | цена |
|---|---|---|
| оставить как есть | текст-описание | $0.0002 за картинку |
| локальные признаки (PIL+numpy) | контраст, края, раскладка, «где текст» — вектор без сети | ноль |
| `flygym` (NeuroMechFly) | модель глаза мухи, оптика и оптокинетика | нужен MuJoCo, на этой машине не проверено |

Второй путь реализуем здесь и сейчас: PIL 12.3.0 и numpy 2.5.1 уже стоят.

### 5.2 Лупы: MUHA уже тормозит, но не так, как ZaLoop

`core/autonomous.py` содержит тормоза, из которых ZaLoop и вырос. Перенос
ZaLoop в MUHA — это пять ступеней, отпечаток `verb|domain|object`, файл
порогов с хешем и мутант-тест. Работы примерно на один заход, и она полезна
независимо от зрения.

### 5.3 Коннектом остаётся справочником

Ни один из проверенных репозиториев не меняет решения: наш коннектом —
подмножество из 1515 узлов (`descending` 1215, `ascending` 256, `sensory` 44),
оптических долей в нём нет. Для настоящего зрения по коннектому нужен был бы
`flygym` или оптические доли из полного FlyWire.
