# МУХА — рой агентов с мозгом мухи

Проект о рое импульсных нейросетей (SNN), собранных на **коннектоме дрозофилы**:
структура связей берётся у настоящей мухи, динамика и обучение — моделируются.
Каждое действие агента проходит через **OS Глаголов** (verb-act + policy gate),
каждый след пишется в **append-only Registry** — не для надзора, а чтобы у роя
была история становления, из которой следующее поколение стартует как из канона
(«золотые яблоки»).

Внутри две половины, и они дополняют друг друга:

| Половина | Что это | Где |
|---|---|---|
| Замысел | философия, источники, RFC трёх подпроектов, инструкция сборщику | корень репозитория и `01/02/03` |
| Код | работающий агент: граф коннектома, LIF, R-STDP, governance, provenance, тесты, схемы | `fly_connectome_agent/` |

## Три подпроекта

| № | Проект | Ядро идеи |
|---|--------|-----------|
| I | **Архив Омеги** (`01-omega-archive/`) | коллективная память, золотые яблоки, Registry как общее бессознательное |
| II | **Рой-Зеркало** (`02-mirror-swarm/`) | гиперэмпатия, гормоны, зеркала Козырева, творческий хаос Улама, медитация |
| III | **Анаклеарный Рой** (`03-anuclear-rhizome/`) | ризома без центра, перенос ауры, анаклеарные нейроны, АРФА-фильтры |

У каждого — свой `RFC-001-architecture.md`, каталог `policy/` и наброски кода в `code/`.
Код в этих каталогах — иллюстрация замысла; рабочий код живёт в `fly_connectome_agent/`.

## Быстрый старт: запустить проверки

```bash
git clone https://github.com/alekseytak/muha.git
cd muha

python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt

./scripts/check.sh          # всё сразу: синтаксис + тесты + схемы манифестов
```

Отдельные шаги:

```bash
.venv/bin/python -m pytest fly_connectome_agent/tests -q          # тесты агента (122)
.venv/bin/python -m pytest fly_connectome_agent/tests -q -k lif   # только LIF
.venv/bin/python -m pytest fly_connectome_agent/tests -q -k stdp  # только обучение
.venv/bin/python scripts/check_schemas.py                         # схемы манифестов
```

Полный научный стек (torch, snntorch, ray, numba, guppy) для проверок не нужен —
он в `fly_connectome_agent/requirements.txt` и понадобится для запусков модели,
а не для тестов.

## Состояние

- Тесты агента: **122 зелёных**, пропущенных нет. Проверка схем — 5 проб,
  проверка синтаксиса — весь python, включая код внутри документации.
- Реализовано: граф коннектома с валидацией и подграфами, разреженный LIF
  (рефрактерность, шум, задержки, детерминированный повтор), разреженный
  reward-modulated STDP с модулятором, декодер действий, verb-act и gatekeeper,
  provenance-лог с проверкой целостности на диске, схемы и примеры манифестов.
- Замысел (01/02/03) — проектная документация и наброски: самостоятельных
  запускаемых систем этих трёх проектов пока нет.

## Честность claims

Коннектом здесь — **структурный каркас**, а не модель мозга. Проект заявляет
только измеренные результаты прогонов (`simulation_result`) и поведение
инженерных слоёв (`engineering_performance`). Не заявляются биологическая
правдоподобность, воспроизведение поведения мухи, сознание, эмоции и квантовые
эффекты в нервной ткани. Динамика нейронов, веса, задержки, параметры
пластичности и привязка к задаче — это **допущения модели**, и они версионируются
вместе с экспериментом (см. `fly_connectome_agent/docs/claim_policy.md`).

## Структура

```text
01-omega-archive/     Проект I: RFC, policy, наброски кода
02-mirror-swarm/      Проект II: RFC, policy, наброски кода
03-anuclear-rhizome/  Проект III: RFC, policy, наброски кода
PHILOSOPHY.md         концепция → источник → модуль (что во что превращается)
SOURCES.md            откуда всё взято: GitHub, arXiv, Cell, доки владельца
AGENT-BUILD-INSTRUCTIONS.md  пошаговая инструкция агенту-сборщику (этапы 0–10)
fly_connectome_agent/ рабочий агент: src, tests, docs, schemas, examples
scripts/check.sh      единая проверка репозитория
scripts/check_schemas.py  пробы схем манифестов (умеют падать)
docs/EXTRACTION.md    откуда репозиторий взят и что в нём починено при переносе
```

## Порядок чтения

1. `SOURCES.md` — откуда взяты данные и идеи.
2. `PHILOSOPHY.md` — гуманитарный слой, переведённый в код.
3. `AGENT-BUILD-INSTRUCTIONS.md` — как это собирать по этапам.
4. `01/02/03` — RFC и политики трёх проектов.
5. `fly_connectome_agent/README.md` — границы кода и что он на самом деле делает.
